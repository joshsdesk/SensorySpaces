## 2025-05-18 - Accessibility Improvements for Icon-Only Navigation Controls
**Learning:** Icon-only buttons used for navigation, mobile sidebars, search clearing, and modal dismissals need descriptive `aria-label` attributes and explicit `focus-visible` styles so keyboard and screen reader users can navigate effortlessly.
**Action:** Always audit icon-only `<button>` elements across layouts and modals to add `aria-label` and `focus-visible:ring-2` focus rings.
